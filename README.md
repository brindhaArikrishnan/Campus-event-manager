# 🎓 CampusConnect – Campus Event & Hackathon Manager

A full-stack web application designed to simplify college event management, hackathon participation, team creation, and student registration through a centralized platform.

## 📌 About the Project

CampusConnect helps students explore campus events, register for activities, create teams for hackathons, and view event information. It also provides event management features and an admin dashboard to monitor events and participants.

This project was developed as a hands-on full-stack web development project to practice frontend development, backend API integration, and database management.

## ✨ Features

- 🏠 **Home Page** – Simple and user-friendly landing page.
- 📅 **Event Management** – Create and manage college events.
- 🔍 **Search & Filter** – Search events and filter by upcoming or completed status.
- 📝 **Event Registration** – Register participants for events.
- 👥 **Team Creation** – Create teams and add team members.
- 📋 **My Events** – Browse and manage available events.
- 🙋 **Participants** – View registered participant information.
- 📊 **Admin Dashboard** – View event statistics and participant counts.
- 🗑️ **Event Management Controls** – Delete events when needed.

## 🏗️ Application Architecture

The application follows a full-stack architecture:

1. **Frontend:** React provides the user interface.
2. **Backend:** Node.js and Express.js handle API requests.
3. **Database:** MongoDB stores application data.
4. **Integration:** The frontend communicates with the backend through REST API endpoints.

## ⚙️ Installation & Setup

### Prerequisites

Install the following before running the project:

- Node.js and npm
- MongoDB database
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/CampusConnect-Event-Manager.git
```

### 2. Open the Project Folder

```bash
cd CampusConnect-Event-Manager
```

### 3. Install Dependencies

Install the dependencies in the frontend and backend directories according to the project's `package.json` files.

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the backend directory and configure the MongoDB connection string and server port according to your backend setup.

Example:

```env
PORT=5000
MONGO_DB_URI=your_mongodb_connection_string
```

**Security:** Never upload your actual database credentials, passwords, or secret keys to GitHub.

### 5. Run the Application

Start the backend and frontend using the commands configured in your project's `package.json` files.

Open the local development URL provided by Vite in your browser.

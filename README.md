## 📌 About the Project

CampusConnect is a full-stack web application designed to simplify college event management, hackathon participation, team creation, and student registration through a centralized platform.

It helps students explore campus events, register for activities, create teams for hackathons, and view event information. It also provides event management features and an admin dashboard to monitor events and participants.

## ✨ Features

- 🏠 **Home Page** – Simple and user-friendly landing page.
- 📅 **Event Management** – Create and manage college events.
- 🔍 **Search & Filter** – Search events and filter by upcoming or completed status.
- 📝 **Event Registration** – Register participants for events.
- 👥 **Team Creation** – Create teams and add team members.
- 📋 **My Events** – Browse and manage available events.
- 🙋 **Participants** – View registered participant information.
- 📊 **Admin Dashboard** – View event statistics and participant counts.
- 🗑️ **Event Management Controls** – Delete events when needed.

The application follows a full-stack architecture:

- **Frontend:** React provides the user interface.
- **Backend:** Node.js and Express.js handle API requests.
- **Database:** MongoDB stores application data.
- **Integration:** The frontend communicates with the backend through REST API endpoints.

## ⚙️ Installation & Setup

### Prerequisites

Install the following before running the project locally:

- Node.js and npm
- MongoDB database
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/brindhaArikrishnan/Campus-event-manager.git
```

### 2. Open the Project Folder

```bash
cd Campus-event-manager
```

### 3. Install Dependencies

Install dependencies according to the `package.json` files in the project and frontend directories.

```bash
npm install
```

If the frontend has its own `package.json`, install its dependencies separately inside that directory.

### 4. Configure Environment Variables

Create a `.env` file in the backend directory if required by your setup.

Example:

```env
PORT=5000
MONGO_DB_URI=your_mongodb_connection_string
```

**Security:** Never upload actual database credentials, passwords, or secret keys to GitHub.

### 5. Run the Application

Start the backend and frontend using the commands specified in their respective `package.json` files.

Open the local development URL provided by Vite in your browser.
